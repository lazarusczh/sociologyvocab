## 五、建议落地顺序

1. **先换 token**（半天）：只改 `:root` 变量与 `--radius` / 间距刻度，不动结构，风险最低、见效最快。
2. **再补组件状态**（1–2 天）：按钮 4 态、选项 3 态、徽章、进度条。
3. **然后做首页重构**（2–3 天）：打卡仪表盘 + 周历 + 今日目标，这是提升感知最强的一步。
4. **最后做练习页专注模式 + 移动端底部导航**（3–4 天）。
5. **遗忘曲线提醒条**建议单独排期——它要新增复习调度算法，不是纯 UI 活。
